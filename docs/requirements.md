# Requirements

## Application Requirements

1. The application prints "Hello World" to standard output.
2. The application is managed using `uv` for dependency and lifecycle management.
3. Python 3.12 or later is required.

## Development Requirements

1. A devcontainer configuration is provided for containerized development.
2. The project uses `uv` for dependency management and virtual environment creation.
3. Run the application with `uv run fullsend-python`.
