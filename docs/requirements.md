# Application Requirements

## Overview

The demo application is a minimal Python program managed with `uv`.

## Functional Requirements

1. The application prints "Hello World" to standard output when run.

## Technical Requirements

1. Python 3.12 or higher.
2. The `uv` package manager is used for dependency management and running the application.
3. The project follows the `src` layout convention (`src/demo/`).
4. A devcontainer configuration is provided for consistent development environments.
