# fullsend-python

A demo Python application that greets the current system user, managed
with [uv](https://docs.astral.sh/uv/).

## Prerequisites

- Python >= 3.12
- [uv](https://docs.astral.sh/uv/) package manager

## Setup

```bash
uv sync
```

## Usage

```bash
uv run demo
```

## Development

A [dev container](.devcontainer/devcontainer.json) configuration is
included for containerized development. Open the repository in
VS Code or any editor that supports dev containers to get a
ready-to-use environment with Python and uv pre-installed.

See [docs/requirements.md](docs/requirements.md) for full application
requirements.
