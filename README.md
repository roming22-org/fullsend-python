# fullsend-python

A demo Python application managed with [uv](https://docs.astral.sh/uv/).

## Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Getting Started

Install dependencies:

```bash
uv sync
```

Run the application:

```bash
uv run demo
```

## Development

Open this repository in a devcontainer for a pre-configured environment with Python and uv.

## Project Structure

```
src/demo/       - Application source code
tests/          - Test suite
docs/           - Project documentation
.devcontainer/  - Dev container configuration
```
