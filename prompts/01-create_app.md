# Create a demo python application

1. The application must do nothing but print "Hello World".
2. .gitignore file should be created/updated if necessary.
3. 'uv' must be used to manage the application lifecycle.
4. A devcontainer.json file must be created, with the proper configuration to allow the app development within that container.
5. Requirements of the application should be documented in a docs folder.
6. README.md must be updated.
7. AGENTS.md must be created.
